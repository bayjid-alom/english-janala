### 📌 About The Project

`English Janala` is an interactive vocabulary learning platform designed to make English learning simple, engaging, and accessible.

Explore vocabulary by lesson, search for specific words, view detailed meanings and examples, discover synonyms, and listen to accurate word pronunciations using the browser's **Speech Synthesis API**.

The project focuses on building practical skills in **JavaScript DOM manipulation, API integration, dynamic content rendering, search functionality, event handling, and interactive UI development**.

---

### 📌 Features

- **Lesson-Based Learning** — Learn vocabulary through structured lessons
- **Vocabulary Search** — Quickly find words using the search functionality
- **Word Details** — View meanings, examples, pronunciation, and synonyms
- **Bengali Support** — Bengali meanings and example explanations
- **Synonyms** — Explore related words to improve vocabulary
- **Speech Pronunciation** — Listen to word pronunciation using the Speech Synthesis API
- **Dynamic Rendering** — Load lessons and vocabulary dynamically from the API
- **Active Lesson State** — Highlight the currently selected lesson
- **Loading Feedback** — Display a loading spinner while fetching data
- **Empty-State Handling** — Show a helpful message when a lesson has no vocabulary
- **Interactive Details Modal** — Explore complete word information in a modal
- **Responsive Design** — Optimized for mobile, tablet, and desktop screens
